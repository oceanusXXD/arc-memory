# 5 结论

我们提出 ARC，将长期记忆构造重新定义为**写入阶段、查询分布感知**的联合结构–内容决策：在显式写入预算内，一个轻量策略一次性决定持久化来源集合与组织架构，执行恰好一次构造；此后查询只读取持久记忆。我们把“同一段历史存在多个同样有效持久化方案”的多解性从噪声变为监督：离线以冻结构建器真实产出候选方案，并以代表性未来查询集合的“平均效用＋查询覆盖率＋三态审核”认证其长期价值，形成执行认证的多正例档案；训练最大化成功方案集合的总概率（边缘似然），并在成功方案之间偏好更低的摊销生命周期成本。内容优先的因子化与“保守–精确”两级预算掩码使该决策在写入时即可安全、高效地解码（掩码正确性、监督性质与摊销分析的完整证明见附录 B/D/G）。离线编译的开销也无需对每个候选全额支付：级联筛查以必要条件剪枝与 Flat 代理探测跳过必然或高概率不合格的方案（漏检界见命题 9），将真实构造调用减少 []% 而档案一致性保持 []（§4.6）。

在 LongMemEval-S 与 LoCoMo 上，ARC 以每题 [] 个摊销生命周期 tokens 达到 [] / []，相对持久记忆基线改善质量–成本前沿（配对检验见附录 H）；写入阶段自适应架构优于固定架构，机制消融确认多正例、覆盖率与内容条件架构各自必要；核心证据重叠诊断为内容优先设计提供了直接证据（LoCoMo 的 \(J\) 值较高，[]）。完整数值、成本拆分、刷新与稳健性结果见附录 E–G；统计协议见附录 H。

**局限。**（1）核心重叠程度随数据域变化：LoCoMo 的会话证据高度集中，而 LongMemEval-S 的多主题历史重叠较低，其质量上限受“写入时保留核心是否覆盖未来证据”约束。我们已用留出证据保留率与主题块备选方案给出分层结论，但跨域自适应粒度仍是开放问题。（2）主配置下每段历史只写入一次；序贯多单元写入时，写入前记忆会从训练时的参考记忆变为策略自己先前的输出，这种“参考–自写”错配的影响需进一步研究。（3）监督编译依赖冻结构建器与审核器的质量；其能力边界即档案质量边界。（4）阈值与裕量在开发集冻结，跨域迁移时需重新校准。

**未来工作。** 将 ARC 扩展到时序多单元写入与增量刷新；在留出证据保留率低的域上探索“写入阶段持久化＋查询阶段轻量补充”的混合生命周期；研究读取器与写入策略的协同优化；以及将执行认证的多正例监督推广到工具记忆、代码记忆等更广泛的持久化场景。（引用待补）
