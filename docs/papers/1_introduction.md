# 1 引言

长期记忆是大语言模型（LLM）智能体跨会话复用历史信息的核心组件：对话、工具轨迹与文档片段持续累积，记忆系统需要将其中值得保留的内容组织为可供后续查询高效访问的持久表示。按写入时机，现有系统分为两类：一类在查询到达时检索并临时组织上下文（query-time）；另一类在历史到达时即完成记忆构造，查询阶段仅执行检索（write-time）。我们研究后一类设定，并将其形式化为预算约束下的联合决策问题：给定新到达的历史批次 \(E_i\)、写入前记忆 \(\mathcal M_i^-\) 与显式写入预算 \(b\)，系统选择持久化的来源集合 \(S\subseteq E_i\) 与组织架构 \(g\in\{\mathrm{Flat},\mathrm{Chain},\mathrm{Tree},\mathrm{Graph},\mathrm{Cluster}\}\)，构造出的持久记忆随后服务多次未来查询。该设定的依据是部署经济性：写入成本一次性发生，读取成本随查询发生，单查询生命周期成本 \(C(N)=C^{\mathrm{wr}}/N+\bar C^{\mathrm{rd}}\) 随复用次数 \(N\) 单调递减（命题 8）；其代价是写入决策必须在未来查询未知时做出，因而不能针对任何单个查询优化。

write-time 构造的既有方法可按构造策略的获得方式分为三条路线。第一条是免训练的提示工程：Mem0、A-MEM、LightMem、Zep 等以人工设计的规则驱动冻结模型完成记忆的抽取、组织与更新；实现简单，但构造质量受限于规则本身：既不随数据分布自适应，也没有系统性的改进机制。第二条是在线强化学习：Memory-R1、Mem-α 与 MemBuilder 以下游问答正确率为奖励、用 PPO/GRPO 类算法训练写入策略，证明了构造是一种可训练的能力；但该路线依赖在线 rollout 与奖励工程（稀疏终止奖励下的信用分配困难，曾促使 MemBuilder 专门引入会话级稠密奖励与组件归因加权），并伴随训练方差与 reward hacking 风险。更根本地，此类方法的奖励来自单个（或少量）查询上的正确性，与 write-time 设定下“服务大量未知未来查询”的目标之间存在结构性错位。我们采用第三条路线：把构造归约为离线监督学习。该路线训练稳定、无需在线交互，且监督直接对齐部署目标。其障碍在于没有现成标签：从历史到持久记忆的映射是一对多的，同一段历史不存在唯一的“正确记忆”。

图 1 总览了这一设定与本文路线：查询时构造使同一段历史被逐查询反复读取与重建，成本随之重复支付（上）；写入时则须在尚不知晓未来查询的情况下，从同样有效的多个 \((S,g)\) 方案中决定保留什么、如何组织（中）；本文从离线编译的多正例已验证集学习序贯写入策略，一次构造、多次复用（下）。

**图 1　动机与方法总览（teaser）。**（上）查询时构造：同一段历史在每个查询上都被重复读取、重建、使用并丢弃，成本随复用次数 \(N\) 重复支付。（中）写入时构造的挑战：未来查询未知、不存在唯一的“正确记忆”，须据此决定保留哪些内容 \(S\) 与如何组织 \(g\)；同一历史的多个 \((S,g)\) 方案可以同样有效，而既有学习路线依赖在线 rollout 与奖励设计。（下）本文方法：离线编译以冻结组件认证候选方案、形成多正例已验证集；策略按“先选 \(S\)、再依 \(S\) 组织 \(g\)”序贯决策，在写入期恰好构造一次，持久记忆随后供未知的未来查询只读复用（无在线 rollout、无奖励设计）。

我们的出发点是把这一对多性质从障碍转化为监督来源。我们给出三个观察。其一，对同一段历史，不同未来查询所依赖的核心证据高度重叠：多数查询反复调用同一小批来源，其余内容信息密度低、访问频率低，在有限写入预算下其构造成本难以被后续使用摊销。我们不主张这部分内容没有价值，只主张其在给定预算下不值得持久化；重叠意味着“写什么”与“如何组织”可以从查询分布出发做统计预测。其二，多解性有三类典型来源：同一事实存在替代证据（任取其一即可）、部分来源需联合才可解释（必须同取）、单一来源同时支持多个事实（一源多用）；且架构 \(g\) 是对已选内容 \(S\) 的组织决策而非独立属性，故 \(S\) 与 \(g\) 耦合，监督必须作用于完整的 \((S,g)\) 组合，这意味着监督应保留全部合格方案，而非指定唯一金标准。其三，一个方案是否合格是可以判定的：每个候选方案都可以用冻结组件真实构造、用代表性未来查询真实考察，并经三态审核自动认证，因此已验证集可以离线编译，偶然通过的概率可以得到统计控制（命题 3），训练可以直接最大化部署效用的可证下界（推论 1）。“多解＋可验证”意味着监督可以离线编译，无需在线试错、人工标签或奖励设计。

我们称该过程为监督编译。离线阶段枚举候选 \((S,g)\)，由冻结的构建模型真实构造持久记忆，再由三个冻结组件分别认证：构建器认证可执行性（schema 合法、解析确定），审核器认证忠实性与信息完整性，读取与回答模型在代表性查询集上认证长期效用。方案仅当通过三态审核、满足平均效用 \(U_i\ge\tau_U\)、查询覆盖率 \(\operatorname{Cov}_i\ge\tau_{\mathrm{cov}}\) 与预算检查时，进入已验证集 \(\mathcal W_b(i)\)。由于每个历史批次要在多个候选上筛选，小查询集会引入偶然通过（spurious pass）的选择偏差；命题 3 给出指数概率界，说明查询集规模与双阈值共同构成对候选集规模的对数级控制（查询集为 i.i.d. 抽样时为概率控制；主配置取全池时按池内多重比较解读，适用域见附录 D.4）。由此得到的监督是执行认证（execution-verified）且多正例的：一次历史更新贡献多个有效目标，而非单一标签。全额认证也不必对每个候选支付：级联筛查（§3.3.5）以零成本的必要条件剪枝与一次廉价 Flat 代理探测，将必然或高概率不合格的方案挡在真实全架构构造之前；入档规则不变，漏检概率受指数界控制（命题 9），实测节省与档案一致性见 §4.6。

基于上述设计，我们提出 ARC（Adaptive Retrieval and Construction）。其训练不需要在线交互、不需要奖励模型、也不构造负例：在已验证集上最小化边缘负对数似然，并附加成本正则，

\[
\min_\theta\ -\log M_\theta(i,b)\;+\;\lambda_c\,\mathbb E_{\rho_\theta}\!\left[\frac{C_i-c_b^*(i)}{c_b^*(i)}\right],
\qquad
M_\theta(i,b)=\!\!\sum_{(g,S)\in\mathcal W_b(i)}\!\!p_\phi(S\mid E_i,b)\,p_\psi(g\mid S,E_i,b).
\]

以成功事件为观测、\((S,g)\) 为潜变量，该目标等价于精确 EM（命题 4）：档案显式枚举潜空间，E 步为精确后验期望，M 步为对已验证轨迹的 \(\rho\)-加权似然上升。梯度仅沿已验证的完整 \((S,g)\) 轨迹回传，保持内容–结构配对（命题 5）；失败方案不获得任何奖励，不因便宜而概率升高（命题 7）；且在采样解码下 \(-\log M_\theta\) 恰为“构造记忆通过与部署同款认证”这一事件的负对数似然，监督信号与部署指标是同一量的两面（命题 6），其与端到端质量的对应由 RQ1/RQ3 检验。合并上述性质即得核心保证：采样解码下部署期望效用有认证下界 \(\mathbb E[U_i]\ge M_\theta(i,b)\cdot\tau_U\)（推论 1）。因此，上述目标最大化的是 oracle 目标的可证下界，训练优化的不是代理指标，而是“部署后对多数未来查询有效”这一事件的认证下界。

策略采用内容优先的因子化 \(P_\theta(S,g)=p_\phi(S\mid E,b)\,p_\psi(g\mid S,E,b)\)：先选内容、再依内容评架构，与核心证据重叠的观察一致；预算处理采用两级掩码：来源阶段以与架构无关的保守上界过滤（命题 1），配对阶段以构建模型 tokenizer 的精确计数做硬检查，保证部署路径不越界。检索器、编码器、构建器与回答模型全程冻结。部署时，新历史到达后策略在一次束解码中联合选择 \(S\) 与 \(g\)，执行恰好一次构造调用；此后查询只读取持久记忆。

实验在 LoCoMo 与 LongMemEval-S 上进行，指标与基线论文对齐（§4.1）。结果预览：ARC 以每题 [] 个摊销生命周期 tokens 达到 [] / []，改善质量–成本前沿，且优势随复用次数增大；写入阶段自适应架构优于按数据集固定的最优单一架构；机制消融确认多正例、覆盖率、内容条件架构与成本偏好各自必要；核心证据重叠诊断（LoCoMo：[]）为内容优先设计提供直接依据。与强化学习训练的 write-time 方法（Memory-R1、Mem-α、MemBuilder）的直接比较及训练开销分析列于附录 E 与 G.3。

我们的贡献如下。（i）将 write-time 持久记忆构造形式化为查询分布感知、预算约束下的联合 \((S,g)\) 决策问题，并以真实生成 tokens 区分预算与生命周期成本；（ii）提出执行认证的多正例监督编译，以三态审核、平均效用与覆盖率阈值从真实构造结果建立已验证集，并给出多方案筛选下偶然通过的概率控制（命题 3）；（iii）提出内容优先的序贯因子化与两级预算掩码，将离线多方案搜索摊销为写入时一次构造、查询时一次读取；（iv）给出以边缘似然为核心的训练目标及其性质（精确 EM、配对保持、无显式失败负例、监督–部署一致，命题 4–7；认证效用下界，推论 1），为 write-time 构造建立在线强化学习之外的监督学习路线：无在线交互、无奖励设计，训练开销与 rollout 数无关；（v）以摊销生命周期成本刻画写入的复用收益，给出成本随复用次数递减及与按查询构造的交叉点分析（命题 8），并在两个基准上给出质量–成本前沿与行为诊断；（vi）给出成本感知的级联筛查编译（命题 9），在不改变入档保证的前提下省去对必然或高概率不合格候选的全额构造，其评估可由日志离线复判零新增调用完成（§4.6）。（引用待补）

范围与假设。ARC 的有效性建立在两个可检验前提上：核心证据重叠（§4.5.1 给出诊断协议与结果，重叠较低时给出主题块备选方案），以及冻结认证器的质量决定监督质量（审核一致性与重复构建稳定性见附录 D）。方法之间的取舍依场景而定：write-time 相对 query-time 的边界由附录 E 的查询时构造变体 ARC-PQ 量化；监督编译相对强化学习的边界由附录 E/G.3 的实测对照给出，在线交互廉价且奖励可靠的任务更适合 RL 直接优化端到端指标。
