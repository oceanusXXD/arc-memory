# 摘要

大语言模型智能体依赖长期记忆复用历史交互中的信息。按记忆的写入时机，现有系统分为两类：一类在查询到达时才构造记忆（query-time），另一类在写入阶段即完成记忆构造、查询阶段仅执行检索（write-time）。我们研究后一类设定：在未来查询未知时，决定保留哪些历史内容 \(S\)、采用哪种组织架构 \(g\)，并受显式写入预算 \(b\) 约束；同一份记忆随后服务多次查询，构造成本按复用次数摊销。这一设定的核心困难在于：从历史到记忆的映射是一对多的，即多个不同的 \((S,g)\) 方案可以同样忠实、对多数查询同样有用；且 \(g\) 是对已选内容 \(S\) 的组织决策，二者耦合，无法归结为单标签监督。

我们提出 ARC，将上述结构转化为可验证的监督并训练一个轻量写入策略，流程分三步。（i）离线编译：对每个历史批次枚举候选 \((S,g)\) 方案，用冻结构建模型真实执行；方案仅当通过忠实性与完整性审核、在代表性查询集上满足平均效用 \(U_i\ge\tau_U\) 与查询覆盖率 \(\operatorname{Cov}_i\ge\tau_{\mathrm{cov}}\)、且序列化长度满足预算时，进入已验证集 \(\mathcal W_b(i)\)；查询集规模与双阈值共同控制多方案筛选下的偶然通过概率（命题 3；查询集为 i.i.d. 抽样时为概率控制，主配置取全池时按池内多重比较解读，适用域见附录 D.4）。全额认证并非对每个候选都必须支付：级联筛查（命题 9）先以零成本的必要条件剪枝，再以一次廉价 Flat 构造与小查询子集做代理探测，将必然或高概率不合格的方案挡在真实全架构构造之外，入档规则与保证不变。（ii）训练：以“构造成功”为观测、\((S,g)\) 为潜变量，在已验证集上优化边缘似然目标

\[
\min_\theta\ -\log M_\theta(i,b)\;+\;\lambda_c\,\mathbb E_{\rho_\theta}\!\left[\frac{C_i-c_b^*(i)}{c_b^*(i)}\right],
\qquad
M_\theta(i,b)=\!\!\sum_{(g,S)\in\mathcal W_b(i)}\!\!p_\phi(S\mid E_i,b)\,p_\psi(g\mid S,E_i,b),
\]

其中 \(\rho_\theta\) 为已验证方案上的后验权重。该目标等价于精确 EM（命题 4），保持 \((S,g)\) 配对（命题 5），不为失败方案构造显式负例（命题 7）；且采样解码下部署期望效用满足 \(\mathbb E[U]\ge M_\theta\cdot\tau_U\)，即训练直接最大化部署效用的认证下界（推论 1）；检索器、构建器与回答模型全部冻结。与以在线强化学习训练写入策略的方法（Memory-R1、Mem-α、MemBuilder 等）相比，ARC 的训练无需在线交互与奖励设计，监督直接来自真实构造结果的离线编译，训练开销与 rollout 数无关。（iii）部署：新历史到达后，策略在一次束解码中联合选择 \(S\) 与 \(g\)，随后仅执行一次构造调用；成本以构造与读取路径的实际生成 tokens 计量，单查询生命周期成本 \(C(N)=C^{\mathrm{wr}}/N+\bar C^{\mathrm{rd}}\) 随复用次数 \(N\) 递减（命题 8）。

实验在 LoCoMo 与 LongMemEval-S 上进行，沿用基线论文的指标定义与评价惯例（LoCoMo 的 F1 与 LLM-judge 准确率、LongMemEval 的 judge 准确率、每题摊销生命周期 tokens），数值在统一重实现协议下报告。ARC 以每题 [] 个摊销生命周期 tokens 达到 [] / []，改善质量–成本前沿；消融分别验证多正例监督、覆盖率约束、内容条件架构与成本偏好的贡献。（引用与数值待补）

## 附：英文对照稿

Long-term memory lets LLM agents reuse information from past interactions. Existing systems differ in when memory is written: some construct memory only when a query arrives (query-time), while others complete memory construction at write time so that queries only retrieve (write-time). We study the latter regime: before any future query is known, the system must decide which historical content \(S\) to retain and which organization \(g\) to adopt, under an explicit write budget \(b\). The same memory then serves many queries, amortizing construction cost over reuse. The core difficulty is twofold: the history-to-memory mapping is one-to-many (several distinct \((S,g)\) plans can be equally faithful and equally useful for most queries), and \(g\) is an organizational decision over the selected \(S\), so the two are coupled and resist single-label supervision.

We propose ARC, which turns this structure into verifiable supervision for a lightweight write-time policy, in three steps. (i) Offline compilation: for each history batch we enumerate candidate \((S,g)\) plans and execute each with a frozen constructor; a plan enters the validated set \(\mathcal W_b(i)\) only if the resulting memory passes faithfulness and completeness audits, attains average utility \(U_i\ge\tau_U\) and query coverage \(\operatorname{Cov}_i\ge\tau_{\mathrm{cov}}\) on a representative query set, and fits the budget. The query-set size and dual thresholds jointly bound the probability of spurious admission under multi-plan selection (Proposition 3; a probability control for an i.i.d. sampled query set, reading as a within-pool multiple-comparison control under the full-pool configuration, see Appendix D.4). Full certification need not be paid for every candidate: a certified cascade screening (Proposition 9) applies zero-cost necessary-condition pruning and a cheap Flat-only proxy probe on a small query subset, skipping full multi-architecture construction for plans that provably or with high probability cannot qualify, while admission rules and guarantees remain unchanged. (ii) Training: treating “successful construction” as the observation and \((S,g)\) as latent, we minimize the marginal-likelihood objective \(\min_\theta -\log M_\theta(i,b) + \lambda_c\,\mathbb E_{\rho_\theta}[(C_i-c_b^*(i))/c_b^*(i)]\) with \(M_\theta(i,b)=\sum_{(g,S)\in\mathcal W_b(i)} p_\phi(S\mid E_i,b)\,p_\psi(g\mid S,E_i,b)\). This objective equals exact EM (Proposition 4), preserves \((S,g)\) pairing (Proposition 5), and constructs no explicit negative examples for failed plans (Proposition 7). Moreover, under sampling decoding the deployed expected utility obeys \(\mathbb E[U]\ge M_\theta\cdot\tau_U\), so training directly maximizes a certified lower bound on deployed utility (Corollary 1). The retriever, constructor, and answer model stay frozen. In contrast to write-time methods whose policies are trained by online reinforcement learning (e.g., Memory-R1, Mem-α, MemBuilder), ARC requires no online interaction and no reward design: its supervision is compiled offline from real construction outcomes, and its training cost is independent of the number of rollouts. (iii) Deployment: when new history arrives, the policy selects \(S\) and \(g\) in one beam decode followed by exactly one construction call; cost is measured in actual generated tokens along the construction and reading paths, and the per-query lifecycle cost \(C(N)=C^{\mathrm{wr}}/N+\bar C^{\mathrm{rd}}\) decreases with the number of reuses \(N\) (Proposition 8).

Experiments on LoCoMo and LongMemEval-S follow the metric definitions of the baseline papers (F1 and LLM-judge accuracy on LoCoMo, judge accuracy on LongMemEval, and amortized lifecycle tokens per query), with all numbers reported under a single re-implementation protocol. ARC reaches [] / [] at [] amortized lifecycle tokens per query, improving the quality–cost frontier. Ablations confirm the contributions of multi-positive supervision, the coverage constraint, content-conditioned architecture, and the cost preference.
